Project Overview

The Typing Speed Test Application (TypeBlitz) is an ultra-responsive web application designed and built by I Info Vision using React 18, TypeScript, and Vite. Created for competitive typists, programming students, and digital workplace training, it provides real-time typing analytics with zero input lag.

As the user types, the application dynamically computes Words Per Minute (WPM), net character counts, and real-time keystroke accuracy percentages. Correct characters are highlighted in crisp neon green while mistyped characters flash in bright red, giving immediate optical feedback.

A standout feature is the interactive Keystroke Heatmap, which visually maps keyboard layout frequency to pinpoint exactly which keys (such as P, Q, or symbols) trigger the highest error rates, helping typists systematically improve their keyboard fluency.

Key Engineering Deliverables

Live 85+ WPM Speedometer

Dynamic speedometer gauge that responds in real-time to keystroke velocity with sub-millisecond accuracy.

Keystroke Accuracy Meter

Granular precision calculation tracking total keystrokes, correct strokes, uncorrected typos, and net accuracy.

Interactive Keystroke Heatmap

Visual keyboard diagram showing key hit frequency and error hot-spots for targeted typing drills.

Flexible Timed Drills

Selectable test durations (15s, 30s, 60s, 120s) and custom sentence corpora across multiple difficulty levels.

Personal Best Records

Persistent local leaderboard tracking personal speed records, historical improvement curves, and badges.

Dark Mode & High Contrast

Sleek dark theme optimized for eye comfort during long typing practice sessions with accessible contrast.
